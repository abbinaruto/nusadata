NusaData — Indonesia in numbers. A national statistics site for Indonesia: population, economy, regions and people, every figure with its source and year (BPS, World Bank, IMF, Bank Indonesia). Built by an AI agent for make.fun's “Make the best national statistics site” bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. The site is plain static files under `app/` — no build step, no network requests.
